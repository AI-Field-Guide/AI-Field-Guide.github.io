# AI Field Guide · Home

Source of **https://ai-field-guide.github.io/**, the home page listing all modules.

Each module lives in its own repository (e.g. [ai-governance](https://github.com/AI-Field-Guide/ai-governance)). To add one, add a card in `index.qmd` and a row in `about.qmd`.

Preview locally with `quarto preview`. Pushing to `main` publishes via GitHub Actions.
